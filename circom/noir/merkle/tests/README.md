# Merkle Library Test Suite

This directory contains the automated testing environment for the Noir Merkle library, verifying tree depths and path validations.

## Positive Vectors
There are 8 positive test vectors distributed across multiple depths. These ensure that valid Merkle proofs generated by the unconstrained helpers successfully pass the constrained `verify_path` logic.

## Negative Vectors
There are 5 negative vectors that ensure the verifier correctly rejects manipulated or invalid inputs. Negative vectors cover:
- Invalid leaves
- Tampered sibling hashes
- Incorrect directional bits
- Mismatched roots

## Tested Depths
- **depth2**: 2 positive test vectors (Tree with 4 leaves).
- **depth3**: 3 positive test vectors (Tree with 8 leaves).
- **depth4**: 3 positive test vectors (Tree with 16 leaves).

## How to Run Regression Scripts
A bash script is provided to automate the positive suite. Execute it from an environment where `nargo` and `bb` are available:
```bash
./scripts/run_positive_suite.sh
```

## Expected Outputs
The script compiles each depth-specific package (`merkle_verify_d2`, etc.) and runs `nargo execute`, `bb prove`, and `bb verify`. For each vector, you should see output indicating successful witness generation, proof computation, and verification, followed by `PASS`.

## Interpretation of Failures
- **`nargo execute` fails**: Usually indicates a failing assertion in the Noir circuit. Check the negative vectors or verify that the test vector parameters are correct.
- **`bb verify` fails**: Indicates a deeper cryptographic inconsistency between the proving key and the proof, or a regression in the Barretenberg backend.
